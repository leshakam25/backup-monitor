Что подготовить

Понадобится до начала установки.

1

Токен компании

В Telegram-боте мониторинга: 🏢 Компании → компания → 🔑 Токен.

2

Папка на NAS

Сетевой путь, куда складывать бекапы, например \\192.168.1.10\backup.

3

Права администратора

На компьютере, где лежат данные, — базы 1С и документы.

Установка

Один раз на каждую машину, где лежат данные.

  1. Скачайте и разблокируйте архив Правый клик по backup-agent.zip → Свойства → галочка «Разблокировать» → OK. Иначе Windows будет предупреждать при запуске.
  2. Распакуйте на локальный диск Например, на рабочий стол. Не на сетевой диск: после запроса прав администратора сетевые диски с буквой не видны.
  3. Запустите Install.cmd и подтвердите права администратора Установщик всё сделает по шагам и задаст несколько вопросов:
    • адрес сервера — просто нажмите Enter;
    • токен компании — установщик проверит его и покажет название компании;
    • папку на NAS — установщик проверит, что туда можно писать.
    7-Zip, если его нет, установщик поставит сам.
  4. Опишите, что копировать В конце откроется Блокнот с файлом заданий и примером внутри — впишите свои папки и время, сохраните и закройте.
  5. Готово Бекапы пойдут по расписанию, а результат каждого будет приходить в Telegram-бот.

Нужно что-то поменять — запустите C:\BackupAgent\Install.cmd ещё раз: текущие значения предлагаются по умолчанию, достаточно нажимать Enter.

Отчёт о каждом бекапе

Сразу после запуска: успешно, с предупреждениями или ошибка — с причиной и размером архива. Успешные приходят без звука.

⏰

Бекап не пришёл

Если отчёта нет дольше положенного — компьютер выключен или задание сломалось, — бот предупредит и будет напоминать раз в сутки.

Сводка и меню

Каждое утро в 09:00 — сводка по всем компаниям. Кнопки Сводка · Компании · Проблемы: история запусков и вывод 7-Zip по каждому заданию.
